1. 프로젝트 명 : 사업 계획서(혹은 제안서) 자동 작성
2. 개요
    - 사업 공고 양식 등 사업의 관련된 파일들과 회사의 보유 기술, 역량, 장점, 매출 기타 등등 여러 정보 소스들의 파일들을 넣으면,
    - 자동으로 사업 계획서(혹은 제안서)를 작성해주는 서비스 개발
     
3. 개발 상세
    1. Phase 1
        - 첫번째 파일 첨부 섹션 : 사업 공고, 사업 계획서 양식 등 기타 사업의 정보들이 담긴 모든 문서들
        - 두번째 파일 첨부 섹션 : 회사 정보들이 담긴 모든 종류의 문서들(기술, 역량, 장점, 매출 등 모든 회사 정보 소스)
        - 위 두 섹션에서 받은 파일들을 기반으로 최적의 작성 개요(대분류, 중분류, 소분류...)를 작성함
            - 이 때, 가장 기본은 공고와 양식(특히, 양식에 있는)에 존재하는 작성 항목 개요를 기본으로 사용
