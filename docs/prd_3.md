1. 프로젝트 명 : 사업 계획서(혹은 제안서) 자동 작성
2. 개요
    - 사업 공고 양식 등 사업의 관련된 파일들과 회사의 보유 기술, 역량, 장점, 매출 기타 등등 여러 정보 소스들의 파일들을 넣으면,
    - 자동으로 사업 계획서(혹은 제안서)를 작성해주는 서비스 개발

3. 개발 상세
    1. Phase 3
        - 본 단계 목표 : Phase 2까지 완성된 사업계획서 본문(Step 1·2·3 결과)을 **국비 사업 제출 양식인 HWPX(가능하면 HWP)로 다운로드** 받을 수 있게 함
        - 국비 사업 사업계획서의 최종 제출 양식은 일반적으로 .hwp 또는 .hwpx
        - 화면에서는 마크다운으로 작성·편집되어 있으나, 사용자가 한 번에 받을 수 있는 형식으로 변환되어야 함

        - HWP/HWPX 출력의 현실적 한계
            - HWP(구버전 바이너리) : 한컴 비공개 스펙. 외부 도구로 안정적 생성 사실상 불가능 → 직접 생성 후보에서 제외
            - HWPX(XML + ZIP) : 구조는 공개되어 있으나 안정적 오픈소스 라이브러리 부족. 표·이미지·스타일 호환성 깨짐 잦음
            - 가장 안정적인 길은 사용자가 한컴 한글에서 직접 열어 저장하거나, 신뢰할 수 있는 변환기를 사이에 둠

        - 현실적 다운로드 옵션
            1) DOCX 다운로드 → 사용자가 한컴 한글에서 열어 HWPX로 저장 (가장 안정적, 사용자가 1 step 추가)
            2) 서버에서 DOCX 생성 후 LibreOffice headless로 HWPX 변환 (자동, 환경 의존성 + 변환 손실 가능)
            3) 사내에 LibreOffice/한컴 변환 서비스가 있다면 그걸 호출하여 HWPX 받기 (가장 깔끔, 인프라 확인 필요)
            4) HWPX 직접 생성 라이브러리 시도 (표·이미지 호환성 risk)
            5) PDF 다운로드 (미리보기/공유용. 재편집 불가)

        - 최종 결정 사항 (Phase 3 진입 전 사용자 확인 필요)
            - 어떤 포맷을 1차 출력으로 할지 (DOCX 안정 / HWPX 자동 변환 / HWPX 직접 생성)
            - 사내 변환 서비스 가용 여부 (DevOps 또는 인프라팀 확인)
            - 본문의 시각화 추천(💡 표·차트 추천 위치)을 실제 표/이미지로 변환할지, 텍스트로만 둘지

        - 출력 통합 구조
            - 표지 (선택) : 사업명·기관명·신청일 등 메타정보
            - 1장. 사전 분석 결과 (Step 1) — 선택적 포함
            - 2장. 사업계획서 본문 (Step 2 아웃라인 + Step 3 본문, 대분류·중분류 순서대로 통합)
            - 부록 : 본문에서 LLM이 인용한 출처 리스트 자동 취합 (Phase 2의 부록 섹션)
            - 양식 사용자가 표지·기관명 등 메타 입력하는 UI 추가

        - 다운로드 화면 사양
            - Step 3까지 완료되면 "최종 결과물 내보내기" 버튼 활성화
            - 클릭 시 포맷 선택 메뉴 : [DOCX] [HWPX] [PDF] [Markdown] [JSON]
            - 표지 정보 입력 (사업명·기관명·작성자·작성일·기타) 선택 가능
            - 다운로드 진행 표시 (변환 호출이 길어질 수 있음)

        - 안내 (사용자 인지 필요)
            - HWPX 자동 변환 결과는 한컴 한글에서 미세 조정이 필요할 수 있음 (표·서식)
            - HWP(구버전) 직접 다운로드는 미지원 — HWPX로 받고 한컴에서 다른 이름 저장 권장

    이후 Phase 4부터는 사용자 계정/협업, 결과물 평가 모드, 다국어 등을 검토 (별도)
