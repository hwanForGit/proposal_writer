1. 프로젝트 명 : 사업 계획서(혹은 제안서) 자동 작성
2. 개요
    - 사업 공고 양식 등 사업의 관련된 파일들과 회사의 보유 기술, 역량, 장점, 매출 기타 등등 여러 정보 소스들의 파일들을 넣으면,
    - 자동으로 사업 계획서(혹은 제안서)를 작성해주는 서비스 개발

3. 개발 상세
    1. Phase 3
        - 본 단계 목표 : Phase 2까지 완성된 사업계획서 본문(Step 1·2·3 결과)을 **국비 사업 제출에 활용 가능한 형식**으로 다운로드 받을 수 있게 함
        - 국비 사업 사업계획서 최종 제출 양식은 일반적으로 .hwp / .hwpx 이지만, 외부에서 안정적으로 생성 가능한 형식이 아니므로 **본 단계에서는 직접 출력하지 않음**
        - 사용자는 다운로드한 DOCX 파일을 한컴 한글에서 열어 "다른 이름으로 저장 → HWPX"로 직접 변환 (한컴이 가장 신뢰성 높음)

        - HWP/HWPX 직접 생성 한계 (참고)
            - HWP(구버전 바이너리) : 한컴 비공개 스펙. 외부 도구로 안정적 생성 사실상 불가능
            - HWPX(XML + ZIP) : 구조는 공개되어 있으나 안정적 오픈소스 라이브러리 부족. 표·이미지·스타일 호환성 깨짐 잦음
            - 결론 : Phase 3은 안정 출력만 제공하고 HWPX 변환은 한컴 한글에 위임

        - 출력 포맷 (1차 목표)
            1) DOCX (.docx) — Word 호환, 한컴 한글에서 열어 HWPX로 저장 가능. **권장 흐름**
            2) PDF (.pdf) — 미리보기·공유·제출용 부수본
            3) Markdown (.md) — 원본 텍스트 (이미 구현됨)
            4) JSON (.json) — 백업/복원용 (이미 구현됨)

        - ★ 1순위 제약
            - 어떤 포맷이든 다운로드 결과물은 **화면에 표시된 마크다운 서식을 그대로 반영**해야 함
            - 글머리 기호, **굵게**, *기울임*, > 인용, 표, 헤딩 위계, 코드 블록, 이모지(📝 🔍 🎯 등), 구분선
            - 화면 출력과 다운로드본의 외형이 최대한 동일해야 함

        - 출력 통합 구조
            - 표지 (선택) : 사업명·기관명·작성자·작성일·연락처 등 메타 정보
            - Step 1 (사전 분석) — 포함 여부 선택
            - Step 2 (아웃라인 구조) + Step 3 (본문) 대분류·중분류 순서대로 통합
            - 부록 (선택) : 본문에서 인용한 출처 리스트 자동 취합

        - 다운로드 화면 사양
            - Step 3까지 완료되면 헤더 [내보내기 ▾] 메뉴에 DOCX·PDF 항목 추가
            - 클릭 시 표지 정보 입력 모달 (선택 입력, 빈 채로도 진행 가능)
            - 다운로드 진행 표시 (수 초~수십 초)

        - 안내 (사용자 인지 필요)
            - 다운로드 본은 DOCX/PDF로만 제공. HWPX는 한컴 한글에서 직접 저장하면 됨
            - 한컴 한글 변환 시 표·이미지 미세 조정 필요할 수 있음

    이후 Phase 4부터는 사용자 계정/협업, 결과물 평가 모드, 한컴 자동화 검토 등을 별도로 진행
